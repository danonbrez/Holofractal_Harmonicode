## Abstract

This paper formalizes the HARMONICODE construction by which a fixed ordered octonion phase algebra is expanded into a recursively addressable 1-, 2-, 3-, 4-, and higher-dimensional relational manifold without changing the underlying basis, commuting ordered phase products, or conflicting with the scalar normalization projection `pi_L(a²)=1`.

The construction uses three independently typed relations: the inherited RML2 geometric phase opposite, the inherited RML4 ordered reciprocal operand, and the symbolic base-pair constructor supplied by the HARMONICODE source relation. The first four relational coordinates are materialized directly; dimensions above four are represented as recursive closure references over the same algebra with exact ancestry. A complete typed `u^72` imaginary-rotation carrier gives a reversible representation of the gyroscopic state. Scalar projection remains a separate operation and therefore does not erase native phase orientation.

## 1. Source-preservation axiom

The canonical source constructor is preserved verbatim:

```text
x=1/y y=-x
(x,y,z,w)²==(Ixy, I-yx, Izw, I-wz)²
```

Let the primitive native channel set be

\[
\mathcal O_4=\{x,y,z,w\}.
\]

The source expressions above are constructor constraints. This theorem does not independently solve, scalarize, reorder, or normalize them.

## 2. Ordered-product axiom

Native phase products preserve orientation:

\[
xy\not\equiv_H yx,
\qquad
zw\not\equiv_H wz
\]

unless an independently applicable registered theorem establishes equality for a specific domain.

Consequently, any representation that discards ordered-product ancestry is not an injective native representation over this phase domain.

## 3. Three relation families

Define three mappings whose types remain distinct.

### 3.1 Geometric phase opposite

Let

\[
R_{phase}:\mathcal O_4\rightarrow\mathcal O_4
\]

be the RML2 geometric opposite:

```text
R_phase(x)=z
R_phase(z)=x
R_phase(y)=w
R_phase(w)=y
```

with involution:

\[
R_{phase}(R_{phase}(s))=s.
\]

### 3.2 Ordered reciprocal operand

Let

\[
R_{ord}:\mathcal O_4\rightarrow\mathcal O_4
\]

be the RML4 ordered reciprocal-operand relation:

```text
R_ord(x)=y
R_ord(y)=x
R_ord(z)=w
R_ord(w)=z
```

with:

\[
R_{ord}(R_{ord}(s))=s.
\]

`R_phase` and `R_ord` are not identified merely because both are involutions.

### 3.3 Symbolic base-pair map

Let

\[
B:\mathcal O_4\rightarrow\mathcal B_4
\]

be the source-bound symbolic base-pair map:

```text
B(x)=Ixy
B(y)=I-yx
B(z)=Izw
B(w)=I-wz
```

where every codomain term preserves the ordered source product appearing in the constructor.

The system therefore carries at least three independently queryable relations for each primitive channel:

\[
(s,R_{phase}(s),R_{ord}(s),B(s)).
\]

This redundancy is deliberate and typed.

## 4. Relational dimensional lift

For a primitive state `s`, define:

\[
D_1(s)=s,
\]

\[
D_2(s)=\bigl(s,R_{phase}(s)\bigr),
\]

\[
D_3(s)=\bigl(s,R_{phase}(s),B(s)\bigr),
\]

\[
D_4(s)=\bigl(s,R_{phase}(s),B(s),B(R_{phase}(s))\bigr).
\]

These are relational coordinates over the same underlying algebra, not declarations of new basis units.

### Theorem 1 — fixed-algebra dimensional expansion

For every primitive `s` in `O4`, `D1` through `D4` are constructible using only the inherited octonion channel set plus typed relation images. Therefore:

\[
\operatorname{Basis}(D_n)=\mathcal O_4
\quad\text{for}\quad 1\le n\le4
\]

in the sense that no new primitive octonion basis element is introduced by the lift.

### Proof sketch

`D1` contains `s`. `D2` adds the image of `s` under the closed map `R_phase`. `D3` adds a symbolic relation witness `B(s)`. `D4` adds the base-pair witness of the already-closed geometric opposite. Every added coordinate is therefore generated by a registered mapping from the existing primitive state and its relation ancestry. No constructor step declares an additional primitive basis element. QED over the implemented v7 domain.

## 5. Higher-dimensional recursion

For `n>4`, the implementation does not materialize an independent `n`-dimensional multiplication table.

Instead, define a closure descriptor:

\[
D_n(s)=\operatorname{Ref}\bigl(D_4(s),n,\mathcal A_n\bigr)
\]

where `A_n` is exact ancestry recording the recursive nesting depth and closure root.

The descriptor must satisfy:

1. same octonion algebra identifier as its root;
2. exact closure-root identity;
3. exact nesting depth;
4. no newly declared primitive basis element;
5. deterministic reconstruction of its ancestry metadata.

### Theorem 2 — recursive scaling without basis inflation

If every `D[n>4]` is a closure reference over `D4` satisfying the five requirements above, relational dimensionality can increase without increasing the primitive basis cardinality.

This theorem is structural. It does not by itself establish a particular latency or compression ratio.

## 7. Scalar projection separation

Let `pi_L` denote the registered local scalar projection with:

\[
\pi_L(a^2)=1.
\]

The gyroscopic/native state belongs to a richer typed domain than the scalar result.

Hence:

\[

for an applicable source-bound projection does not imply:

\[

\]

Likewise, unit projection cannot establish:


unless an additional applicable native theorem independently closes such an equality.

### Theorem 3 — unit-projection compatibility

The dimensional-lift manifold and `pi_L(a²)=1` are non-contradictory because the first preserves native relational identity while the second operates on a registered scalar projection surface.

The two statements inhabit different typed equality relations.

## 9. Deterministic closure and contradiction avoidance

The construction prevents three common category errors.

### 9.1 Relation conflation

It forbids treating `R_phase`, `R_ord`, and `B` as interchangeable merely because each relates the same primitive channel set.

### 9.2 Projection/native conflation

It forbids promoting a shared scalar projection into native equality.

### 9.3 Representation/authority conflation

It forbids promoting the reversible `u^72` carrier into an alternate canonical transition authority.

Thus the dimensional lift remains deterministic while preserving the noncommutative information required by ordered products.

## 11. Falsification conditions

The implemented theorem fails if any admitted test demonstrates one of the following:

- `R_phase` ceases to be the registered RML2 involution;
- `R_ord` ceases to be the registered RML4 involution;
- the base-pair map differs from the preserved source constructor;
- ordered products are silently commuted;
- `D[n>4]` introduces a new primitive basis;
- typed carrier restoration does not reproduce the represented gyroscopic state;
- a bare phase coordinate is treated as sufficient for full native restoration;
- scalar unit projection erases native ordered identity;
- the layer independently mutates VM81 or mints canonical Hash72/Hash216 state.
