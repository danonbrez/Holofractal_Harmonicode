## Governing scientific model

I061 preserves two independent evidence axes.

### Axis A — formal validity

Formal validity is established from repository-native proof lineage:

```text

  -> Wolfram formalization identity
  -> Lean 4 theorem identity Hash72
  -> Lean 4 dependency identity Hash72
```

The I060 Lean identities must be present before the PhysicsCellWall candidate is
constructed.

The construction order is frozen as:

```text

-> formal validity axis
-> empirical correspondence axis
-> intrinsic proof-binding Hash72
-> PhysicsCellWall candidate
-> Lane 5 5184 / Hash216 candidate topology
-> PhysicsCellWall admission
```

Post-hoc proof attachment does not satisfy I061.

### Axis B — empirical correspondence

Empirical correspondence is separate from formal validity.

If a mechanic claims measured physical behavior, I061 requires:

- a declared operating domain;
- calibration or experimental evidence;
- declared unit and dimension;
- exact measured and predicted values where represented by the I061 carrier;
- exact residual;
- exact error bound;
- residual within that declared bound;
- deterministic replay receipt Hash72.

Formal proof cannot substitute for empirical correspondence.

Empirical agreement cannot substitute for formal validity.

A purely formal/symbolic mechanic may explicitly declare that it is not yet
claiming measured physical behavior. In that case empirical evidence is not
required for the candidate, but the candidate cannot be represented as a
validated measured-physics claim.
