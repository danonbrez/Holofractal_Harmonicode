# HHS Glossary

**Admission gate** — A typed boundary deciding whether an expression or transition may enter a locally canonical state.

**Canonical state** — The authoritative exact representation associated with its identity, ancestry, and active contracts.

**Closure** — A condition in which all required residuals, identities, dependencies, and authority checks are satisfied.

**Entropy neutral** — Exactly recoverable globally; not necessarily unchanged or uncompressed locally.

**Equality membrane (`==`)** — A local equivalence/admission relation, not automatically global scalar equality.

**Hash72** — A 72-position symbolic phase and witness projection used with stronger canonical identities.

**Looking Glass** — Bidirectional traceability from admitted premises to conclusion and back through the receipt lineage.

**Ouroboros closure** — Deterministic termination when a recursive optimization revisits a canonical state or meets another declared halt condition.

**Receipt** — The evidence object binding a transformation to its canonical inputs, ordered execution, outputs, ancestry, and validation.

**Typed operator** — An operator whose meaning is determined by runtime contracts and local context rather than glyph appearance alone.

**VM81** — The native 81-cell runtime/execution geometry used by HHS.
