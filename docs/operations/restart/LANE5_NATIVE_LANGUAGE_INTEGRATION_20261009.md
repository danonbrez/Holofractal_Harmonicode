## What the new implementation does

The new Python bridge calls the **existing compiled native** Lane 5
`hhs_exact_pass219_lane5_mediate_candidate` entrypoint through the
repository-owned `hhs_uqcel_ctypes_bridge._LIB` loaded lazily.

It retains the exact `HHSExactPass219Lane5MediationRequestV1` and receipt
C layouts, verifies ABI version/namespace and every receipt echo, checks all
native HNAN/VM5184/RNA candidate-only flags, and refuses canonical authority.

Callers must supply *already prepared* exact native uint64 signature
fields for request, candidate, parent Hash216, 5184 address, hydration,
compression, capability registry, learning iteration, and RNA prepared/decision
states, plus 1..64 known Hash216/capability references. No signature is
silently derived by truncating arbitrary BigInt, hashing plaintext prompts,
or converting full canonical state to a scalar.

The caller must retain a complete fixed-width 5184-character native state
and ordered 216-character prompt/response transition witness; neither is
exposed in ordinary model-visible result projections. The returned record
contains the native closure/mediation signatures and exact reference
signatures, but **does not** claim that those 64-bit signatures are a
losslessly reversible replacement for raw VM5184 state.

## What this does not yet certify

This is an operational bridge into the **genuine native C mediator** with
typed caller-prepared inputs. Unit tests use an explicitly fake C function
to verify ABI projection and fail-closed negative controls.

A caller-supplied signature is not independently authenticated here, and
the wrapper therefore marks
`external_signature_provenance_independently_verified=false`.
The full RNA preparer and signed environmental VM81 admission must verify
the relationship to the protected source state; that dependency must not
be bypassed or downgraded to a mere metadata flag.

The assistant already calls the native Lean ordered prompt/response tensor
gate after generating a candidate. The Pass 219 ethical training layer is
currently used mostly for optional candidate retrieval context. It does not
yet feed the full C mediator with authenticated RNA signatures for every
assistant candidate. **No end-to-end full integrated closure is claimed.**

The native Pass 215 precise seven-token fixture remains bounded and must
not be called general generation.
