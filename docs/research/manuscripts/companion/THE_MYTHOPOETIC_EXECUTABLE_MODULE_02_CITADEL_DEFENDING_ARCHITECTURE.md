# 1. Module Purpose

Module 1 defined the Polymorphic Adversary as a substrate-independent corruption class:

\[
W=(D,T,G,M,E)
\]

whose strongest state is Terminal Inversion.

Module 2 defines the defending architecture required to recover from that state.

The defenders are not a heroic opposite army.

They are a distributed set of **non-interchangeable system functions**.

The Citadel survives only when authority, memory, provenance, admission, succession, dissent, and repair remain distinct enough to audit one another.

Define the defending architecture:

\[
\mathfrak{D}
=
(K,A,L,G,C,X,H)

- \(K\) = King / lawful mutation authority;
- \(A\) = Architect / structural memory and dependency reconstruction;

- \(G\) = Guardian / selective admission membrane;
- \(C\) = Child or Apprentice / successor-state inheritance;

- \(H\) = Harmonizer / repair-forward coordination.

No coordinate may silently absorb the others.

Thus:

\[
K\neq A\neq L\neq G\neq C\neq X\neq H
\]

\[
