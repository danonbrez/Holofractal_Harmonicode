## Binding semantics
1. `==` denotes an ordered constraint gate: the gate must close for the expression to be meaningful. It is not a host-language equality/Boolean result.
2. `n/d` denotes a rank-1 **ordered tensor circuit** `n ⊗ d`. The numerator denotes periodicity modulus; the denominator denotes quantization unit. A slash is **not** permission to perform scalar division or cancel ordered factors.
3. Bare `P` retains universal `P/∆` orientation, reciprocal `∆/P`, with primitive `∆=1` at the canonical normalization layer. The course also writes `∆=u^(-180)` at the shell-representation layer; do not identify these representations without a native typed-equivalence witness.
4. Gate evaluation is sequential, with typed dependence on predecessor states, source addresses, and provenance. No commuting, ordinary scalar cancellation, host exponent substitution, or rank flattening.
5. HNAN denominator-zero branch: **gain exactly 1; return original swarming curvature; leave phase unchanged; emit no phase write**. The bypass is distinct from a successful nonzero-divisor evaluation; it must be recorded in a diagnostic witness without inventing a phase transition.
6. Only authorized VM81 execution can commit state or mint canonical Hash72/Hash216 receipts. Source identity, C++ cell-wall declaration-completeness, Pass159 replay, and model-level derivation are not mint authority.
