## 8. Exact Schrödinger gate

The exact finite-step identity is:

~~~text

=

=
ExpSym(-i H_n Delta_t_n/u72) psi[n]
~~~

This is exact at every committed node for the selected logarithm branch.

The forward finite difference:

~~~text

~~~

is not equal to the logarithmic Hermitian Hamiltonian at finite step for the
nonzero modes.

Wolfram proves for k=1,...,8:

~~~text

~~~

Therefore the finite-difference Schrödinger expression is an egress
coarse-grain approximation, not the exact finite-step Hamiltonian identity.

If a continuous interpolation:

~~~text

~~~

is separately selected, its differential Schrödinger equation is exact on
that interpolation and reproduces the committed nodes.

## 9. Stone-theorem boundary

Stone's theorem applies to a strongly continuous one-parameter unitary group
and gives its self-adjoint generator.

A single finite-order matrix U by itself does not select one unique logarithm.

For I025 the correct logical order is:

~~~text
unitary U
+ explicit logarithm branch
+ optional continuous interpolation
-> Hermitian generator H
~~~

not:

~~~text
U^9=I
-> unique H without branch data
~~~

## 10. Eight-fold degeneracy: exact scope

The 8-fold multiplicity is an exact property of U_72 and therefore of a
Hamiltonian defined solely as the selected logarithmic function of U_72.

It is not yet a theorem that every future HHS interaction Hamiltonian preserves
that degeneracy. Additional cycle-dependent terms could split it.

Thus the falsifiable structural prediction closed by I025 is:

~~~text

-> 9 phase levels
-> multiplicity 8 per level
~~~
