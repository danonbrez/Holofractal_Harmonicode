## Model residency law

Let `W` denote an imported frozen source-model archive and `P(W)` a verified native projection derived from it.

The residency invariant is:

```text
W in external archive domain
W not-in canonical VM81 state
identity(W) anchored inside PQC trust domain
P(W) crosses boundary only after verification
```

A runtime request that attempts any of the following SHALL fail closed:

1. copying the raw external weight blob into canonical VM81 state;
2. allowing a model/provider inference result to commit canonical state directly;
3. bypassing the signed environmental/PQC VM81 handoff;
4. treating model-file presence, provider readiness, GPU execution, or service registration as canonical authority;
5. accepting a native projection whose source identity/provenance anchor is absent;
6. accepting a projection that has not passed the required exact/native verification contract.

The source archive MAY remain available outside the cell wall for hydration, migration, comparison, repair, or replacement. Once sufficient admitted native topology exists, runtime dependence on the source archive MAY decrease or reach zero without changing canonical authority.
