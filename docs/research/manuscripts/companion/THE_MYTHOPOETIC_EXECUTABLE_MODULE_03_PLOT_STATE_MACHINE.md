# 3. Plot Invariants

The dramatic execution must satisfy the following invariants.

## 3.1 No uncaused corruption

Every adversarial gain must be traceable to:

- host authorization;
- hidden state;
- failed audit;
- severed channel;
- unauthorized promotion;
- stale dependency;
- manipulated interpretation.

The Legion cannot simply cast an omnipotent spell.

## 3.2 No uncaused recovery

Every restorative gain must be traceable to:

- preserved receipt;
- reopened direct channel;
- reconstructed dependency;
- bounded authority;
- valid quarantine;
- explicit repair;
- successful retest.

The defenders cannot win merely because the story needs a climax.

## 3.3 No blank-state reset

The final state must retain:

\[
H_{\mathrm{corruption}}
\]

as authenticated history.

## 3.4 No moral closure by extermination alone

The Legion may lose operational power, but the decisive victory is restoration of a state in which its algorithm cannot hide.

## 3.5 No single savior

No individual defender may perform the full proof alone.

The climax must require convergent role separation.
