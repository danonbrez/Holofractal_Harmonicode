# Pass 199 Claim Boundary

Pass 199 is limited to a single-host durable worker fabric.

It does not claim:

- multi-host consensus;
- arbitrary subprocess or provider execution;
- automatic compiler mutation;
- automatic runtime admission;
- live DigitalOcean acceptance;
- physical hardware calibration;
- candidate-worker mutation authority.

Canonical mutation remains one VM81/Pass 190 authority path. Branch candidates are immutable evidence only.
