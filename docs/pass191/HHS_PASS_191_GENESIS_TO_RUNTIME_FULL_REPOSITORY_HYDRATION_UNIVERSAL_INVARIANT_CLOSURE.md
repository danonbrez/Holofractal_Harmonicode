## 29.1 Discover

Enumerate all repository-visible objects and historical references according to explicit inclusion/exclusion policies.

## 29.2 Preserve

Capture exact bytes or exact text, encoding, lexical widths, ordered list positions, source path, repository commit, and provenance before semantic normalization.

## 29.3 Classify

Assign object kind, pass ownership, generated/external status, authority class, and hydration policy.

## 29.4 Parse

Build syntax trees without losing exact source spans, delimiters, operator order, repeated tokens, comments where relevant, or membrane identities.

## 29.5 Type

Resolve scalar, matrix, tensor, ordered-product, list-circuit, phase, address, group, receipt, artifact, and constraint-join types.

## 29.6 Index

Assign stable canonical object IDs, Hash72 lineage witnesses, Hash216 ordered topology identities, and registered pass/function IDs.

## 29.7 Link

Construct dependency, lineage, call, registry, provenance, receipt, replay, reciprocal, and symmetry edges.

## 29.8 Bind

Attach inherited pass requirements and the universal Pass 191 invariant envelope.

## 29.9 Candidate

Create immutable candidate hydration or mutation states without altering authoritative state.

## 29.10 Admit

Validate typing, capability, resource bounds, reciprocal closure, Lo Shu constraints, global symmetry, history continuity, and replay requirements through VM81 authority.

## 29.11 Execute

Execute only admitted registered operations through the canonical runtime path.

## 29.12 Verify

Run positive, negative, differential, parity, symmetry, receipt, replay, and dependency-scoped tests.

## 29.13 Receipt

Emit one Hash72 receipt for each authoritative decision and committed mutation.

## 29.14 Replay

Reconstruct the same result from repository-visible state and declared external inputs.

## 29.15 Close

Resolve every job and object to a bounded explicit state with actionable evidence.
