## Authoritative scope

## Implemented surface

The runtime provides:

- immutable content-addressed source capture;
- bounded media detection and adapters for text, Markdown, source code, JSON/JSONL, CSV, HTML/XML, PDF, image, audio, video, HHS objects, and binary objects;
- media-spoofing, source-size, compressed-container, malformed-input, and authorization rejection;
- deterministic modality-neutral tokens with exact source offsets and registered temporal or spatial coordinates;
- non-destructive token/chunk dependency graphs;
- exact sparse `81 × 64 = 5,184`-bit projections stored as 648-byte Pass 163 frames;
- Hash72 projection and receipt identity plus Pass-165-domain-separated Hash216 ingestion identity;
- repetition, ordering, dependency, novelty, and contradiction objects;
- exact-rational residual-only weight proposals bounded to `1/16` per ingestion epoch;
- stale-root, contradiction, noncanonical-weight, and range rejection;
- singleton VM81-governed learning admission with no worker commit authority;
- append-only checksummed durable journal;
- atomic durable frontier replacement;
- incomplete-tail and stale-frontier quarantine;
- deterministic restart recovery and complete-record tamper rejection;
- deterministic replay of source, weight, and VM81 state;
- strict C11 projection, residual, bounded-source, and exact-weight primitives.

## API

```text
hhs_backend.pass165_server:app
/api/runtime/multimodal-ingress
```

Operations include status, bounded Base64 ingress, invariant queries, receipt lookup, replay, and durable recovery. Setting `HHS_PASS165_STORAGE_DIR` enables the durable service; otherwise the API retains the bounded in-memory reference mode.
