## Abstract

This paper formalizes the finite local-state algebra of the Pass 220 81-cell
Sudoku/Lo Shu geometry.

The canonical 9x9 Sudoku seed carries one nine-cell wrapped neighborhood at
each of its 81 anchor cells. A local neighborhood is the center plus the
positive and negative directions of the four inherited wrapped directional
families `x,y,z,w`, giving exactly nine local slots:

[
\mathcal N_9 =
\{0,\pm x,\pm y,\pm z,\pm w\}.
]

The visible 3x3 neighborhood is therefore the local projection of the
four-direction carrier.

For the canonical seed, all 81 oriented nine-cell neighborhoods are distinct.
An exact reciprocal involution combines 180-degree anchor reversal with the
symbol complement `d -> 10-d`. It maps every anchor to its opposite anchor,
has exactly one fixed point, and partitions the 81 oriented neighborhoods into

[
40\text{ reciprocal pairs}+1\text{ fixed center}=41
]

distinct entangled fingerprint classes.

The center fixed class is exactly the canonical Lo Shu nucleus.

The implementation additionally binds each fingerprint to the inherited
Pass 220 Lo Shu-relative bigint carrier, proves an exhaustive 81-anchor
reachability codec, and joins the cell algebra to the exact quadratic
number-theory recurrence generated by `G = 2 + P`, `P^2 = 3`.

This is a read-only exact witness/reference layer. It does not create a second
VM81 authority and does not mint canonical Hash72 or Hash216 state.

Define the reciprocal transform (ho) on a 3x3 fingerprint by

[

\rho(F)_{i,j}=10-F_{2-i,,2-j}.
