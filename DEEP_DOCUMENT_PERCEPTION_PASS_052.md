## Doctrine

```text
PDF parser output ≠ PDF
OCR text ≠ page image
page image ≠ document
table extraction ≠ table source
document graph ≠ document identity
provider agreement ≠ automatic truth
provider disagreement ≠ failure
```

The Runtime remains the canonical observer. Document providers act as instruments/transducers; their observations become typed projections only after Runtime-governed ingress and witnessing.
