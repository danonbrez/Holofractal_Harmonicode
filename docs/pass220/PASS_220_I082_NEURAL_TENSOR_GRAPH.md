`sample_native_neuron(neuron_id, nucleus_index)` checks both identifiers,
uses `build_lane5_vm81_candidate` and
`validate_lane5_vm81_candidate`, and inherits a candidate
Hash216 hydration witness. The explicitly supplied nucleus index must come
from the authorized native binding; the graph layer does not guess it from
the node ID. No 86-billion-node allocation or eager edge materialization
is attempted.

The I070 bridge remains candidate-only. A candidate Hash72 string is not a
canonical Hash72 commit receipt. Actual graph topology, native tensor
closure, and canonical state mutation remain under existing Lane 5 authority.
