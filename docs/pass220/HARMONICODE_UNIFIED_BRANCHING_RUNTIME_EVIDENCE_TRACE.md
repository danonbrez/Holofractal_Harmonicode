## Shared-algebra interpretation, not module-number preference

The exact user-supplied Modules 113 and 114 remain preserved verbatim. Module 114's text calls its *specific embedded Γ interpretation* a correction to Module 113, without establishing that an entire Tensor outranks another Tensor. Both sources must retain typed provenance. Contradictory active conditions create algebra-internal candidate branches. Branch creation is not proof of eventual equality or permission to commit an incompatible result.

The next implementation inspection must verify that the **same ordered compound constraint evaluator** (rather than a candidate-only GPU manifold or an isolated witness) can represent distinct active constraints simultaneously, preserve all branch inputs, and route them through the existing HNAN and VM81 admission boundary.
