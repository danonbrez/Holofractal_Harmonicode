# Pass 219 — PQC Membrane Speculative Hydration I13

## Purpose

I13 operationalizes the I12 external-model boundary as a typed C ingestion membrane. A frozen probabilistic model is an external speculative semantic oracle. Its archive and weight tensors remain outside the PQC cell wall. Only an exact, provenance-bound, five-lane candidate projection may cross the membrane, and only the inherited signed VM81 environmental admission path may mutate canonical state.

I13 does **not** establish a second transition authority, Hash72 authority, Hash216 authority, persistence authority, or probabilistic arithmetic authority.

The sole state-changing successor remains:

```text

```

The I13 helper `hhs_exact_pass219_pqc_membrane_ingest_i13` is deliberately `static inline`; it is a source-level verifier and delegator, not a new exported mutation symbol.

### PQC-W3 — Frozen-source identity survives projection

Every crossing projection carries an immutable source manifest containing:

- a 64-byte source digest;
- a nonzero source architecture identifier;
- a 216-character Hash216 projection-root anchor;
- explicit immutable/outside-PQC/provenance flags.

The source digest is provenance, not state authority. Different model families may contribute candidates, but their identities remain distinguishable even if exact admission later converges them onto the same canonical VM81/Hash216 route.

### PQC-W4 — Candidate cannot commit itself

The projection has no commit function and rejects both:

```text

GPU ranking, language-model output, algebraic solving, five-lane routing, cache lookup, and source-model agreement remain candidate evidence only.

### PQC-W5 — Verified metabolism can remove oracle dependency

Oracle removal is an evidence transition, not an assumption. I13 encodes three integer-counted lifecycle phases:

1. `ORACLE_DEPENDENCY` — the external source may produce speculative candidates; no severance is authorized.
2. `CACHE_HIT_DOMINANCE` — verified canonical routes exist and can be reused; the external source remains available for unmapped frontiers.
3. `NATIVE_AUTONOMY` — allowed only when `required_route_count > 0`, `verified_route_count >= required_route_count`, the external oracle is disabled, and explicit severance authorization is present.

This makes autonomy a repository-testable state transition. I13 does not infer completion from elapsed time, model agreement, cache size alone, or an unverified performance claim.

## Invalid speculative candidates

Within I13, an external hallucination is operationally an unverified candidate. It cannot reach canonical state when any required invariant fails. Rejection includes, but is not limited to:

- source archive residency violation;
- missing source identity or Hash216 provenance root;
- five-lane/Holo4 authority reinterpretation;
- H2 coordinate outside 36-bit range;
- missing H5 prime-surface coordinate;
- non-exact or incomplete closure proof;
- nonzero `Delta e` or `Psi`;
- false `Omega`;
- probabilistic payload crossing;
- candidate-frame Hash72 mismatch;
- direct-model or non-VM81 commit request;
- failure of the inherited signed environmental admission path.

## Inter-model geometric convergence

Candidate agreement across Llama-family, Qwen-family, Mistral-family, native, or other frozen sources is not itself proof. Each source retains separate provenance. Deduplication occurs only after independent exact projection and the inherited VM81/Hash216 admission machinery establishes the same canonical route identity.

Accordingly, I13 permits semantic convergence without allowing model consensus to become transition authority.
