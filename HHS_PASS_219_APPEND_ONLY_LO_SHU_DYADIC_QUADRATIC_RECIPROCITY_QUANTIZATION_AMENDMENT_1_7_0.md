This amendment formalizes the equation supplied for direct translation among the ordered `x,y,z,w` phase algebra, the `u^72` phase ring, the dyadic/diadic harmonic scale generated by `b`, the Lo Shu tensor polynomial numeral surface, and the `xy/yx` quadratic-reciprocity orientation pair.

# G1. Lo Shu tensor polynomial numeral surface

The canonical Lo Shu tensor polynomial is:

```harmonicode
L_H = {
  {b^4,       c^4,       b^2},
  {c^2,       b^2+c^2,   b^4+c^2},
  {b^6,       a^2,       b^2*c^2}
}
```

under the inherited exact projections:

```harmonicode
a^2 = 1
b^2 = 2
c^2 = 3
```

so its integer projection is the Lo Shu square:

```text
4 9 2
3 5 7
8 1 6
```

The fixed numeral lifts used by this amendment are:

```harmonicode
N1  := a^2
N2  := b^2
N3  := c^2
N4  := b^4
N5  := b^2+c^2
N6  := b^2*c^2

N8  := b^6
N9  := c^4
N12 := c^2*b^4
N36 := b^4*c^4
N72 := b^6*c^4

N66 := b^6*c^4-b^2*c^2
N5256 := (b^6*c^4)*(b^6*c^4+a^2)
ZERO_L := c^2-c^2
```

No fixed scalar numeral in the native theorem is authoritative merely because a conventional integer glyph is convenient in explanatory prose.

# G2. Two typed projections of `u`

This amendment SHALL distinguish:

```text
u_phase  — cyclic phase-ring projection
u_q      — exact dyadic quantization-metric projection
```

The inherited phase closure remains:

```harmonicode
u_phase^(b^6*c^4) = a^2
```

which projects conventionally to `u_phase^72 = 1`.

The quantization metric is not required to have scalar magnitude one. It is constrained by G3.

The two projections may share one native source identity only through an explicit projection record and reconstruction witness. One projection SHALL NOT overwrite the other.

# G3. Dyadic quantization normalization relation

The primitive metric relation is:

```harmonicode
(b^2)^(a^2/((c^2*b^4)*pi_scalar(xy)))
=
b^2 * u_q^(b^6*c^4+a^2)
```

For the declared unit-product scalar projection:

```harmonicode
pi_scalar(xy) = a^2
```

the relation becomes:

```harmonicode
u_q^(b^6*c^4+a^2)
=
(b^2)^(a^2/(c^2*b^4)-a^2)
```

Applying one complete `N72` cycle produces the fixed-numeral-free closure form:

```harmonicode
u_q^((b^6*c^4)*(b^6*c^4+a^2))
*
(b^2)^(b^6*c^4-b^2*c^2)
=
a^2
```

Its conventional scalar projection is exactly:

```text
u_q^5256 * 2^66 = 1
```

or equivalently `u_q^5256 = 2^-66`.

The native theorem is the polynomial form above, not the decimal evaluation of its positive-real root.

# G4. Quadratic-reciprocity orientation lift

For admitted odd prime/integer reciprocity inputs `p,q`, define the Lo Shu parity residue:

```harmonicode
epsilon_L(p,q)
:=
Mod(((p-a^2)*(q-a^2))/b^4, b^2)
```

The ordered reciprocal phase lane is:

```text
epsilon_L == ZERO_L  -> xy
epsilon_L == a^2     -> yx
```

The corresponding native `u^72` phase address is:

```harmonicode
Phi_QR(p,q)
:=
Mod((b^4*c^4)*epsilon_L(p,q), b^6*c^4)
```

Therefore the two reciprocal orientations are:

```harmonicode
xy <-> ZERO_L mod (b^6*c^4)
yx <-> b^4*c^4 mod (b^6*c^4)
```

which conventionally project to the half-cycle pair `0` and `36` modulo `72`.

The scalar sign pair `(+1,-1)` is a compatibility projection of the richer ordered `xy/yx` provenance; it is not the native identity of the pair.

# G5. Universal Quantization Constraint Enforcement Law

Define the profile:

```text
UQCEL := ConstraintJoin(
  LO_SHU_POLYNOMIAL_NUMERAL_SURFACE,
  DYADIC_QUANTIZATION_NORMALIZATION,
  U72_PHASE_CLOSURE,
  XY_YX_QUADRATIC_RECIPROCITY_ORIENTATION,
  VM81_ORDERED_PHASE_WITNESS,
  HASH72_HASH216_LINEAGE
)
```

A candidate state declaring the UQCEL profile is admissible only if every applicable typed component is satisfied.

`ConstraintJoin` does not mean that the metric value of `u_q`, the phase value of `u_phase`, and the `xy/yx` reciprocity lane are one scalar value. It means that they are projections/witnesses of one admitted constraint state and must remain mutually compatible under their registered mappings.

The law is universal over its declared admission profile: every candidate that claims the profile SHALL be checked. It does not claim that every possible external mathematical, biological, or physical object belongs to that profile.

# G6. Existing exact ABI correspondence required by the law

The inherited exact ABI already supplies the required ordered phase witnesses:

```text

phase_product(y,x) -> ordered tag yx, phase N36
```

and the VM81 ordered address plane:


For UQCEL conformance, the `xy/yx` witness MUST be cell-independent as an algebraic relation while each cell/address occurrence retains its distinct VM81 address identity.

The current ABI compatibility test is evidence of substrate correspondence. It is not by itself evidence that canonical VM81 admission already invokes UQCEL as a mandatory gate.

# G7. No-float rule

All canonical UQCEL evaluation SHALL use exact integer, reduced-rational, symbolic exponent, modular, and ordered phase representations.

No positive-real decimal approximation to `u_q`, no trigonometric phase approximation, and no floating-point evaluation of the Lo Shu polynomial may authorize or mutate canonical state.
